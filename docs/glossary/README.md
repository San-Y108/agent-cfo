# Glossary

| 术语 | 定义 |
| --- | --- |
| Payment Plan | 根据贡献记录生成的结构化付款计划 |
| Risk Check | 确定性的预算、白名单、限额、token 和重复检查 |
| Human Approval | 资金执行前的人类授权门槛 |
| CAW | Cobo Agentic Wallet，AgentCFO 的受控资金执行层 |
| Audit Report | 执行时生成的计划、风控、审批和执行证据快照 |
| mock | 不触发真实外部系统的演示模式 |
| simulation | 对未来行为的计算或预览，不代表已执行 |
| testnet | 测试网络上的真实链上调用，不等于生产资金 |
| real mode | 调用真实外部 provider 的运行模式，仍可能限定为 testnet |
| theme | 一组有共同目标的 report、PRD、handoff 和实现任务 |

新增术语时给出代码或文档事实来源，避免把营销词当领域概念。
