# docs/backup — 文档备份区

本目录**仅存放备份**，不放日常阅读的业务文档。

## 用途

| 类型 | 命名 | 说明 |
| --- | --- | --- |
| README 合并前备份 | `README-YYYYMMDD-pre-polish.md` | 执行 [`docs/plans/README-merge-plan.md`](../plans/README-merge-plan.md) Phase 0 时生成 |
| preview 归档 | `README.preview-archived.md` | 2026-06-13 从根目录迁入 |
| README 合并前备份 | `README-20260613-pre-polish.md` | 2026-06-13 Phase 0 生成 |

## 纪律

- 备份文件**只读参考**；事实核对以备份为准，但不要直接改备份内容代替正式文档
- 新备份用日期后缀，不覆盖旧备份
- 技术运行手册拆出后放在 [`docs/backend/`](../backend/README.md)，**不**放在本目录
