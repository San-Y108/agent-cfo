## 3. 已知问题与风险

1. **TypeScript 错误**：`components/ui/aceternity/` 下未跟踪的文件（`1.tsx` ~ `hero-8.tsx`）有大量类型错误，原因是缺少依赖（`@tabler/icons-react`, `react-wrap-balancer`, `react-fast-marquee`, `react-icons/hi2`）。这些文件未被项目引用，暂不影响构建。
2. **亮暗色支持**：Console 目前以暗色为主，但已添加 `dark:` 前缀和 `bg-surface` token，支持未来扩展。
3. **AnimatedNumber 限制**：目前只在 Analytics 的 `totalVolume` 上使用了 `AnimatedNumber`，其他 KPI（如 gasSaved, txCount）是字符串格式，不适合直接替换。
4. **Agent 页**：`app/console/agent/page.tsx` 已有基础结构，但 3D 角色是占位符（`Bot` 图标 + `Sparkles`）。
