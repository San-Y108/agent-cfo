# AgentCFO logo/icon pack

Contents:
- `svg/`: standalone transparent SVG files. Some are official-source-derived or simplified approximations where direct binary download was unavailable.
- `png-512/`: transparent 512x512 PNG exports from `svg/`.
- `node-svg/`: ready-to-use circular glowing node icons.
- `node-png-512/`: transparent 512x512 PNG exports from `node-svg/`.

Official source links checked:
- Cobo: https://www.cobo.com/cobo-logo.svg
- Safe{Wallet}: https://safe.global/images/common/safe-logo-wallet.svg
- MetaMask: https://metamask.io/assets and https://github.com/MetaMask/brand-resources
- Sepolia fallback / Ethereum: https://ethereum.org/assets/ and https://ethereum.org/images/assets/svgs/eth-diamond-rainbow.svg
- Sablier: https://github.com/sablier-labs/branding/tree/main/icon/svg
- Drizzle ORM: https://github.com/drizzle-team/drizzle-orm/blob/main/misc/readme/logo-github-sq-dark.svg
- Framer: https://www.framer.com/brand
- GitHub Octocat / Invertocat: https://brand.github.com/foundations/logo

Notes:
- Cobo, Safe, MetaMask and Sablier marks are trademarks; for public/commercial use, check each brand guideline.
- Sepolia does not have a canonical independent logo, so Ethereum diamond is used as fallback.
