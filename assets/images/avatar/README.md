## 规格

- 角色头像：正方形或接近正方形，JPG；
- 吉祥物：透明背景 PNG；
- 文件名使用稳定英文 slug；
- 不保存二维码、群聊截图、手机号或其他个人敏感信息。

## 更新流程

原文件先进入 `inbox/`，确认公开许可后裁切、命名并移入本目录。随后更新根 README 和前端运行时镜像，最后删除 inbox 原文件。
