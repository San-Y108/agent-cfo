## 规则

- 图片必须来自真实界面或明确标注的设计图；
- mock、testnet、real 状态需要在截图或说明中可辨；
- 替换图片时保持稳定文件名，避免 README 断链；
- 压缩图片时保留足够的文字清晰度；
- 不提交带 API key、私钥、后台账户或未脱敏钱包信息的截图。
